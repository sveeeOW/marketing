# Во всём виноват маркетинг — жёлтая версия с движущимся hero-фоном

Готовая статическая версия сайта для Netlify или Vercel.

## Что изменено
- Акцентный цвет заменён с зелёного на жёлтый.
- В hero-блок добавлен зацикленный движущийся градиентный фон.
- Движение фона ограничено первым экраном.
- Форма размечена под Netlify Forms.

## Деплой
### Netlify
Перетащите ZIP или папку в Netlify → Deploys.

### Vercel
Создайте новый проект и загрузите содержимое папки как статический сайт.

Для формы на Vercel понадобится подключить Formspree, Telegram webhook, CRM webhook или другой обработчик.
